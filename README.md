# PunyaMods media

Public preview graphics for [Punya Feiopar](https://thunderstore.io/c/lethal-company/p/PunyaMods/PunyaFeiopar/) and [Stitch Eyeless Dog](https://thunderstore.io/c/lethal-company/p/PunyaMods/StitchEyelessDog/).

Both reskins are inspired by real pets: Punya, a long-haired grey cat, and Stitch, a Jack Russell terrier. The page artwork combines owner-provided reference photographs with previews of the released mod assets.

Punya's asset previews are rendered in Blender; Stitch's previews are captured inside Unity with the stock animation controller. These graphics show the cosmetic changes, while the enemies retain their original gameplay behavior. The texture references were created with ImageGen and adapted to the game assets.

This repository contains page artwork and descriptions. Install the mods from their Thunderstore pages.
